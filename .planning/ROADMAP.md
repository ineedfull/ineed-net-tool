# 首版实施路线
1. 建立独立 Vue/Electron 应用与同系列设计变量。
2. 完成 IPv4 计算、VLSM、保存规划和分配记录。
3. 接通受控原生任务：扫描、Ping、Traceroute；所有任务切页持续、支持停止。
4. 完成结果与规划持久化、回环和 UI 验证，打包具名 .app 并运行给用户验收。

每阶段采用端到端 MVP 方式。内部规划默认顺序执行；不发布远程仓库，不修改既有两个工具。

## 项目化网络维护扩展（2026-09-21）

已实现：项目与办公室 / 视频监控场景模板、完整 IP 台账与批量登记、维护记录、诊断项目归属、SQLite 迁移与事务、Excel 模板及导入导出。使用边界和验证记录见 `docs/network-projects.md`。后续仍保留跨平台真机验证的独立范围。

## IP 统一双视图（2026-09-21）

探测、扫描历史、网段与项目台账统一支持表格 / 紧凑网格；默认显示持久化，台账用途与最近响应分层展示，大网段按区块加载。详见 `docs/ip-views-2026-09-21/README.md`。

已实现大型场景模板：独立内外网地址空间、八个业务分区、三运营商线路台账、跨网规则编辑 / 排序 / 启停、SQLite 持久化及 Excel 可选三表往返。仅维护规划，不下发现场设备配置。详见 `docs/enterprise-2026-09-21/README.md`。
