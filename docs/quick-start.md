# NetTool 快速上手

[返回首页](../README.md) · [下载安装](https://nettool.ineedfull.com/downloads/) · [完整功能参考](feature-reference.md)

本指南按当前仓库源码整理。官网安装包可能早于源码修复；请在「关于」核对版本及构建信息，具体下载文件的发布日期以下载页为准。

目标：创建一个办公室项目，登记两个静态 IP，运行一次本机 Ping，再导出交付资料。先熟悉规划、台账、诊断和导出的关系。

## 1. 安装桌面版

从下载页按操作系统与 CPU 架构选择安装包。NetTool 当前只有 Electron 版；Electron 自带 Chromium，资源占用相对较大。具体文件与平台验收范围见下载页和[打包说明](desktop-packaging.md)。

浏览器预览可以体验本地规划，真实诊断与 Excel 导入导出需要桌面版。

## 2. 创建办公室项目

进入「项目工作台 → 新建项目」，名称填「办公室上手练习」，选择「小型办公室」模板，使用默认地址空间 `192.168.10.0/24`。创建前核对预览：

| 项目 | 示例结果 |
| --- | --- |
| 网段 | `192.168.10.0/24` |
| VLAN | `10` |
| DHCP 范围 | `192.168.10.100`～`192.168.10.199` |

模板创建的是规划与网关预留记录，不会自动配置电脑网卡、交换机或 DHCP 服务器。示例地址不要求与当前电脑的真实网络相同。

## 3. 登记两个静态地址

进入「IP 地址台账」，选择刚创建的网段，分别登记：

| IP | 设备名称 | 设备类型 | 状态 | 位置 |
| --- | --- | --- | --- | --- |
| `192.168.10.10` | 办公打印机 | 打印机 | 预留 | 一层办公区 |
| `192.168.10.11` | 文件服务器 | 服务器 | 预留 | 一层机柜 |

两个地址都在网段内，避开网关及 DHCP 池。同项目、同 VLAN 的重复 IP 会被拒绝。切换表格与网格，核对地址、名称和状态。

「预留/在用/检修」是人工台账状态，在线探测是另一种信息；台账建议空闲和探测无响应都不能证明现场地址没有占用。

## 4. 做一次本机诊断

保持当前项目不变，打开 Ping，目标填 `127.0.0.1`，选择有限次数（例如 4 次），其余参数先保留默认值，再启动。

正常情况下能看到本机回包、时延和收发统计。任务结束后，到「诊断记录」查看结果及「Ping 原始记录」，需要时导出 TXT。系统权限或命令缺失造成失败时，原始输出能帮助区分原因。

这一步只验证本机回环；它不表示办公室设备已经联网，也不会自动探测模板网段。运行中的诊断绑定当前项目；结束或停止任务后再切换项目。

## 5. 导出与重新导入

回到项目工作台，点击「导出 Excel」，选择本地保存位置。导出包含当前项目规划资料、台账等内容，不受当前界面筛选影响；诊断历史不包含在项目 Excel 中，需要单独导出。

如需验证交换流程，使用「导入 Excel」选择刚导出的文件，检查预览后确认导入为新项目。导入不会按同名覆盖原项目。当前工程导出为 27 表，旧版工作簿兼容范围、必填列和限额见[项目与 Excel](network-projects.md)。

Excel 是项目交接格式；完整工作区备份需先退出应用，再复制整个用户数据目录，见[开发指南](development.md)。

## 6. 遇到问题先查这里

| 现象 | 检查方法 |
| --- | --- |
| 地址登记被拒绝 | 核对当前项目、网段、VLAN、重复 IP，以及是否占用网关或 DHCP 池 |
| Ping 无响应 | 先查看本轮原始输出；目标不响应 ICMP、权限、命令或网络都可能影响结果 |
| 不能切换项目 | 先结束或停止当前诊断任务 |
| Excel 导入失败 | 保留工作表名、首行表头和字段格式；按提示的表名/行号修正，成功预览后再确认 |
| 导出后没有诊断记录 | 项目 Excel 和诊断导出用途不同，诊断记录需在对应页面单独导出 |
