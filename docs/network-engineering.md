# 企业办公室与园区：场地需求和容量规划

第一阶段将工程需求与现有地址规划关联。设备、接口和连接清单已在后续 B1 切片补齐；PoE/上联带宽已在 B2 补齐，现场验收与交付已在 C 补齐；本页说明场地需求、接入端口和地址容量的输入依据。

## 组织现场

在项目的“场地与需求”中建立楼栋、楼层和区域。楼层隶属楼栋，区域可以直接放在项目下，也可以属于楼栋或楼层。简单办公室可以只建立区域；较大园区按位置层级组织。

现场位置与业务网段分别记录。同一楼层可以有办公、访客、管理等多张网，同一张业务网也可以被多层楼共同使用。

## 登记业务需求

每条需求包括区域、名称、类型、当前数量、增长预留、每单位地址与接入端口数、静态/DHCP、关联的已保存网段和备注。按现场实际规模填写，当前数量留空表示尚未确定，0 表示已确认没有当前需求。

有线办公终端默认占 1 个地址、1 个接入端口；无线客户端默认占 1 个地址、0 个物理接入端口；AP 默认占 1 个地址、1 个接入端口。AP 与无线客户端分别登记。服务器、多网口设备可按本阶段的整体需求填写单位数，具体设备与接口连接在“设备与连接”中另行登记。

编辑已有需求时切换类型会保留已填写的数量、预留和自定义单位；需要恢复该类型的建议参数时，点击“采用类型默认值”，仅替换每单位地址数、端口数和地址分配方式。新需求选择类型会带入这三项默认值，已填写的数量与预留继续保留。

同一终端的有线和无线使用关系需要在需求划分时考虑：不能把同一物理接入重复计算。如果同一设备确实需要多个同时存在的地址，也需要按实际地址需求登记。

预留计算按每条需求向上取整：

```text
预留数量 = ceil(当前数量 × 增长预留百分比 / 100)
规划数量 = 当前数量 + 预留数量
地址需求 = 规划数量 × 每单位地址数
端口需求 = 规划数量 × 每单位接入端口数
```

例如一层有 40 个有线终端和 4 个 AP，各留 20%：终端 40+8=48，AP 4+1=5，共需 53 个业务接入端口。无线客户端另登记，其物理端口默认是 0。

## 区域端口校核

为每个区域填写可用业务接入端口总数。先扣除上联、坏口、专用接口以及互斥复用接口；本阶段不会根据总接口数推断这些占用。

系统按区域汇总需求，显示所需端口、可用容量、余量和问题。容量留空表示待补充，0 表示明确无可用端口。已知小计超过容量时显示不足；还存在未知数量时也会保留待补充提示。

## 网段地址校核

将需求关联到项目中已经保存的网段。系统跨区域合并同一网段的需求，实际网关只占用 1 个地址，与台账中预留网关不重复相加。

分别检查：

- 总地址需求与 CIDR 可用容量。
- DHCP 需求与已配置的 DHCP 池容量。
- 静态地址需求与排除 DHCP 池、网关后的容量。

缺少关联、实际网关或 DHCP 池会说明需要补充什么；`/32` 单主机不强制要求网关，`/31` 依 IPv4 规则保留两个可用地址。

点击网段缺项或容量问题会返回“地址规划”，并保留原先尚未保存的规划草稿。按问题中显示的网段名称找到对应已保存网段补充参数，目前不会自动选中或滚动定位网段。

需求描述整体目标规模，不与已登记 IP 条数直接相加。登记量展示为参考；容量足够也不表示现场地址已空闲或设备已配置。不同网段 ID 分别计算，本阶段不推断多个重叠网段是否实际共享同一地址池。

## 修改与交接

修改需求后重新计算容量；已有网段、网关和登记地址由地址规划维护，需求变化不会自动重分配 IP。删除被引用的位置或网段前，需要先处理相应需求或容量关联，避免留下失效引用。

工程资料随项目保存在现有 SQLite 中，旧项目无需重新建立。项目 Excel 在原台账之外包含位置、业务需求、接入容量与校核结果；导入根据输入重新计算，校核结果不能作为可编辑的通过证明。导入仍创建独立新项目，不覆盖原项目。

无线覆盖与 AP 选型仍需现场勘测；本阶段记录数量和点位需求，不能据此确认覆盖率。三运营商双网继续是现有场景模板，场地需求也适用于普通单出口办公室。

## 设备、接口与连接

项目“设备与连接”与场地页共用区域。先建立区域，再添加交换机、路由器、防火墙、AP、终端、服务器或其他设备；接口单独登记业务接入、上联或其他角色，以及可用、预留、停用状态。设备实体与 IP 台账分别维护，不自动复制。

连接清单显示两端设备、区域和接口。两端必须属于不同设备，且为可用接口；每个接口只能参与一条连接。允许无连接设备、冗余链路及物理环路。连接为用户登记，不代表在线、连通或验收通过。不自动探测网络。

编辑记录可删除；确认框说明依赖，保存校验拒绝仍被引用的删除。先解除连接再删除接口或改变其可用状态，先删除/移走接口再删除设备，先移走设备再删除区域。失败保留当前草稿；取消后可重新编辑。项目切换清除原项目编辑状态。

设备表显示总接口、可用、已连接、空闲、预留、停用数量。区域业务容量只统计可用的业务接入接口，包含其中已连接接口；不包含上联、其他、预留和停用接口。需求含增长预留，与业务总容量比较，不再叠加到连接占用。手填接入容量独立显示供核对，不覆盖、不相加。无设备或无接口为待登记，未知需求为待补充，已知需求超过容量为不足。所有结果按已登记输入统计，不证明现场容量充足。
