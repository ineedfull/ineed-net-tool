# NetTool 工程规划 B1：设备、接口、连接与占用

承接用户已批准的工程调试、验收和交付方向，以及阶段 A 的企业办公室/园区路线。本轮完成设备与接口清单、连接关系、占用统计及 Excel 交接。PoE/上联带宽估算、现场验收关联另作后续切片；本轮不新增网络探测或自由绘图编辑器。

## 用户行为

项目工作台新增“设备与连接”页签，与“场地与需求”共用位置数据。可登记交换机、路由器、防火墙、AP、终端、服务器和其他设备，逐个登记接口并连接两个设备的接口。界面提示先在场地页建立区域，支持跳转。设备与 IP 台账分别表达物理工程与地址登记，不互相自动复制。

设备必须关联现有区域；接口必须属于本项目设备。接口角色为业务接入/上联/其他，状态为可用/预留/停用。连接必须指定不同设备的两个可用接口；同一接口只能参与一条连接。删除被引用的设备、接口、区域，或把已连接接口改为预留/停用应拒绝并说明应先解除什么引用。修改接口所属设备造成自连也应拒绝。

以连接清单表达实际录入的拓扑，显示两端设备、接口、区域及备注。连接表示用户规划/登记，不表示在线、连通或完成验收；允许无连接的设备，允许冗余链路和物理环路，不判断 VLAN/协议互通。

按设备显示总接口、可用、已连接、空闲、预留、停用数量。按区域显示已登记可用业务接入接口总量、其中已连接与空闲数量，与阶段 A 业务需求（含增长预留）比较。可用业务总量包括已连接的业务口；不能拿剩余空闲数与全部目标需求比较，也不能把需求再加到连接占用上。上联/其他/预留/停用不计入业务容量；库存无设备/无接口时为待登记，未知需求保留待补充，已知需求超过已登记容量给出不足。显示“按已登记接口统计，未登记设备不纳入”；结果不证明现场容量充足。阶段 A 手填接入容量继续保留，B1 不自动覆盖、不与其相加，区域同时显示手填值供核对。

## 数据契约

在现有可选 `project.engineering`（version=1）中新增可选 `infrastructure`：

```js
{ version: 1, devices: [], interfaces: [], links: [] }
// device: { id, locationId, name, kind, model, note }
// interface: { id, deviceId, name, role, state, note }
// link: { id, fromInterfaceId, toInterfaceId, note }
```

设备 kind= switch/router/firewall/ap/endpoint/server/other；role=access/uplink/other；state=available/reserved/disabled。每项目最多 500 设备、5000 接口、2500 连接。ID沿用工程 ID：非空字符串≤100、无控制字符；设备/接口/连接间和原有工程记录间不得重复。名称1～100、model≤200、note≤1000；同设备接口名称经 trim 后必须唯一，设备允许同名但 UI 显示位置区分。数据校验拒绝错误类型、未知版本、失效引用和重复占用。`infrastructure` 缺省保持缺省；显式空对象与未启用可区分。删除时不静默级联。

新增纯领域模块 `src/domain/infrastructure.js`：常量、空结构、校验、ID重映射、报告。`engineering.js` 集成验证/重映射，统一入口覆盖项目保存、SQLite 加载和导入。保持原 SQLite schema、workspace version、工程 version、应用 ID 和数据路径不变。导入为新项目，位置/设备/接口/连接 ID全部重建，引用保持；旧工程/旧项目不自动写新属性。

## Excel

保留旧五/八/十二表工作簿支持；本轮增加可选输入表“工程设备”“设备接口”“接口连接”，输出表“接口占用”。用工作簿本地 E/P/C 编号引用，区域沿用 L 编号，不写内部 UUID。填写说明中加独立“设备连接版本”标记，启用为空也可往返，缺省旧数据不自动启用；显式未知版本、重复版本、只存在部分输入表（启用时）或孤立新表数据拒绝。新表包含数据时必须存在工程位置等原三张输入表。

输出表按输入重算，不信任导入的派生结果。输入沿用严格单元格规则：拒绝公式、链接、富文本、非法数字/引用；中文枚举、冻结首行与合理列宽。读取/校验错误不落盘，导入仍为新项目。最大合法输入可写出并回读，单个结果单元格不聚合无限问题文本。

使用现有 DesktopDialog、FeedbackBanner、按钮/表格/语义 tokens。设备/接口/连接分组清楚；编辑/删除均可键盘操作。保存 busy、防重复提交、项目切换及失败保留草稿遵循现有工作台。表格局部滚动，浅/深主题、普通/大字、展开/折叠侧栏、920×620窄窗口均可操作，弹窗页脚可见。
