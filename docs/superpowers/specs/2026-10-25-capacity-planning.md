预算仅引用本项目设备。PoE需引用本项目连接和其两个不同端点，source/target必须是该连接两端（方向由用户指定）；上联from/to必须与其引用连接的已保存from/to完全相同。业务项只引用本项目上联参数。删除被引用的设备/接口/连接/上联，或更改已关联连接的端点造成参数失配，须拒绝并提示先处理校核引用，不静默级联。接口所属设备修正后报告按其当前归属重算；保持接口身份和两端约束。新增模块 `src/domain/capacity-planning.js`，既有 `validateInfrastructure` 集成可选验证，`remapInfrastructure` 集成新ID与设备/接口/连接/业务引用重建。报告从整个项目验证后生成，不变异输入。

## PoE 估算

输入功耗为受电设备端W，单口与整机预算均为供电端W。线路损耗预留是工程师明确填写的估算比例，不是按线长推断，也不是IEEE供电标准认证。公式清楚显示：

```text
供电端需求W = 向上取整到0.001W(设备端功耗 × (100 + 损耗预留%) / 100)
单口余量 = 单口供电预算 - 供电端需求
整机可规划预算W = 向下取整到0.001W(整机预算 × (100 - 整机预留%) / 100)
整机已知需求 = 本设备所有已登记PoE负载的供电端已知需求之和
```

逐连接比较单口预算与需求，按供电接口所属设备汇总后比较整机可规划预算。已知需求超限为risk；未知功耗/损耗不补0，整机保留已知小计和未知负载数且余量null，已有超限仍为risk。缺单口预算使负载待补充但其已知需求仍可汇总到整机。存在负载却未登记整机预算时生成该设备待补充行；只有整机预算没有任何负载时为待登记负载，不称“满足需求”。源设备行状态应纳入其负载的单口risk/pending，避免整机预算够而单口不足时整体显示通过。

例：2个设备各12W、损耗25%，供电需求每个15W，总30W；预算40W预留20%，可规划32W，余量2W；单口预算14W则单口不足，尽管整机还有余量。冗余供电需按实际每条连接分配，系统不自动减半、不合并电源，也不将同一负载的全部功耗自动复制到多条连接。没有填写标准匹配、线缆/环境等资料时不能据此宣称PoE兼容或现场供电通过。

## 上联估算

本版本明确按全双工链路分别校核两个方向。端点速率由工程师填写，连接容量取两端较小值，不从业务接口数量或其他线路推断。主备和多条链路逐条计算，不加总，不提供LAG吞吐保证或自动路由推导。

```text
可规划带宽Mbps = 向下取整到0.001Mbps(min(起点速率,终点速率) × (100 - 预留%) / 100)
业务规划数量 = 当前数量 + ceil(当前数量 × 增长% / 100)
业务估算Mbps = 向上取整到0.001Mbps(规划数量 × 单设备Mbps × 并发% / 100)
每方向需求 = 关联该上联且属于该方向的业务估算之和
每方向余量 = 可规划带宽 - 本方向需求
```

先计算每条业务再求和；forward/reverse互不相加。count/mbpsPerUnit/concurrency任一未知，该业务结果null并计入其方向未知数；该方向余量null。已知小计超过确定容量仍risk；只有一个端点速率时不能判通过，但若已知需求已超过该端点可规划上界，则可判不足并保留缺项。没有业务项时pending；只有一方向业务时另一方向已知需求0（清楚标注无业务项），整体由实际已登记项决定。场地需求数量与流量项独立，不自动叠加。更改需求参数立即重算；不修改既有工程/IP/连接。

例：起点1000Mbps、终点100Mbps、预留20%→80Mbps；40个终端、增长20%、单端2Mbps、并发50%→48Mbps，正向余量32Mbps；反向业务60Mbps独立校核不与48相加。未知并发保持pending。所有比较、向上/下取整和聚合用整数毫瓦/千比特每秒或等效精确算法，不能因二进制小数或中间乘法误差误判边界；不得在逐行求和前丢失精度。设计限额下聚合应保持安全整数，不通过放宽小数或截断回避。

## 报告与 UI

报告包含enabled、status、powerBudgets/poeLoads/uplinks/trafficDemands结果、issues和basis（具体输出字段由Task1报告定稿供后续消费）。status为ok/pending/risk；risk优先，缺项与不足均保留；显式空计划pending，未启用以明确空状态表达。结果逐行显示单位、输入依据、公式、已知小计、未知数量及余量；结论用“按已登记参数估算”，不替代现场验收。

项目页签“PoE与带宽”，提供前往“设备与连接”，新建整机预算/PoE负载/上联/业务项及编辑删除，避免挤入已有设备表单。PoE选连接和供电端时自动带出受电端；上联选连接自动带出两端快照。业务方向显示真实端点，不只显示英文。表单拒绝空输入变0；ID引用用下拉、界面显示设备/区域/接口。更换参数关联对象仍以可见字段和验证为准，不暗改已有记录。新增/编辑/删除标题准确。

复用DesktopDialog、FeedbackBanner、语义tokens，项目keyed挂载，保存失败保留草稿，busy防重复提交且焦点保持模态，切项目不能误写，删除有依赖说明。表格局部滚动；浅/深、普通/大字、展开/折叠菜单、1440×900与920×620共16组合均检查四类表单和页脚。UI/Excel共用纯报告，不复制计算。
