# 工程 Excel 交接契约（版本 1）

入口为 `electron/excel.cjs`，工程表转换在 `electron/engineering-excel.cjs`。领域验证与计算使用 `src/domain/engineering.js`；导入仅返回预览数据，创建项目仍由既有 projectImport 重建内部 ID，Excel 读取不写数据库。

静态 `electron/templates/NetTool-网络项目模板.xlsx` 五表文件保持不变。动态模板/导出有原五表、三张互联表、三张工程输入表和容量校核，再加 B1 四张设备连接表、B2 五张PoE与带宽表共二十一表；旧五/八/十二/十六表仍可导入且不添加虚构需求。互联解析仅检查三张互联表，办公室工程不要求双网规划。

所有输入表第 1 行为不可修改表头，第 2 行起为数据。以下顺序就是 A、B、C…列顺序；星号是必填列。

| 表       | 按列顺序的字段                                                                                                                         | 上限 |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 场地位置 | 位置编号*、上级位置编号、位置类型*、位置名称*、备注                                                                                    | 500  |
| 业务需求 | 需求编号*、区域编号*、需求名称*、业务类型*、当前数量、增长预留百分比*、每单位地址数*、每单位接入端口数*、地址分配方式*、网段编号、备注 | 1000 |
| 接入容量 | 容量编号*、区域编号*、可用业务接入端口、备注                                                                                           | 500  |

导出位置按输入顺序生成 L001…，需求 D001…，容量 C001…；网段沿用 N001…。上级位置、需求区域、容量区域、需求网段均使用相应编号，不能填写内部 UUID。需求与容量只能关联区域。位置类型下拉为楼栋/楼层/区域；业务类型为有线办公/无线客户端/无线 AP/摄像机/服务器/打印机/其他；分配方式为静态/DHCP。表头冻结，设置列宽、整数格式、筛选与可编辑单元格边框。

当前数量与可用端口留空是 null（未知），0 是明确零；其他数字必填，均为整数。数量与端口 0～1000000，增长百分比 0～1000，每单位地址/端口 0～16。增长填写 20 表示 20%，不能输入 Excel 百分比。全部记录编号跨三表唯一，每区域最多一条容量。位置层级、名称/备注长度及网络引用由领域校验，错误带输入表/行；公式、链接、富文本拒绝。任何工程输入有数据必须保留全部三张输入表。

填写说明新增一行，A 列为固定标签 `工程资料版本`，B 列在启用工程时为数字 1，否则空白（行号位于静态说明末尾之后，不依赖固定行号）。该可见标记保留启用但为空的工程对象；有输入行但无标记推定为版本 1，未知版本拒绝导入。填入版本 1 同样要求三表完整。说明中提供数量、ID、限额与只读结果指引。

容量校核为只读保护表，导入完全忽略其内容/表头（包括被篡改的结果），导入后以真实输入重新计算。A～M 为校核类型、需求编号、区域编号、网段编号、名称、单位、目标/已知需求小计、容量/地址需求、剩余/端口需求、未知需求条数、公式与输入依据、校核状态、问题。

报告先给总体状态，然后需求、区域端口、网段总地址/DHCP地址/静态地址行。需求 G/H/I 为计划数量/地址需求/端口需求；区域和网络 G/H/I 为已知需求小计/容量/剩余，按校核类型与单位阅读。K 列说明 ceil 预留公式、每单位输入、CIDR/地址池/实际网关依据及台账登记仅参考。未知值显示待补充，未知条数单列，风险与待补充问题全部保留；不能用已知小计或某个剩余值替代最终状态。旧项目无工程时输出表为空，不宣称容量充足。

最大输入的问题输出：总体行 M 列仅显示全部/待补充/容量不足的问题数量，完整问题逐条放在“问题”行，绝不拼接全部问题到一个单元格或截断。问题行 B/C/D 保留需求/区域/网段工作簿编号，K 为领域 issue code，L 为对应严重程度（待补充/容量不足），M 为完整 message；非数值问题的单位/数值列留空。所有 issue 按领域报告顺序输出，需求/区域/网段行本身仍保留相关问题。合法最大 1000 条未知且未关联网段的需求也不会超过 Excel 单元格 32767 字符限制。

工程数字列（业务需求 E～H、接入容量 C）在转为数字前检查实际读取单元格的数值格式。非空输入使用 `0%`、`0.00%` 或任一分段中有有效百分比符号时拒绝，并标明表/行/单元格，防止显示 100% 的存储值 1 被误解为增长 1%。普通数字 20 仍表示增长 20%，普通数字 1 表示 1%。引号内的百分号是字面显示，例如 `0"%"`，可以接受且不缩放。ExcelJS 在读取 XLSX 时删除反斜杠转义，`0\%` 会变成 `0%`，无法可靠区分，因此也拒绝；请改用普通数字格式或引号内字面百分号。不读取/猜测原始压缩 XML 来修复库丢失的信息。

## B1 可选设备连接表

`填写说明` 新增独立“设备连接版本”：启用为数字 1，缺省为空；不改变工程版本 1。显式启用空清单可往返，空表和空标记不会自动启用。支持旧五/八/十二表工作簿，B1 格式为十六表；B2 当前生成二十一表，旧十六表仍可导入。

| 表       | 关联方式               | 用途                                          |
| -------- | ---------------------- | --------------------------------------------- |
| 工程设备 | E001…；区域复用 L001…  | 名称、类型、区域、型号、备注                  |
| 设备接口 | P001…；设备引用 E 编号 | 接口名、角色、状态、备注                      |
| 接口连接 | C001…；两端引用 P 编号 | 连接与备注                                    |
| 接口占用 | 派生输出               | 由输入重算设备/区域占用和问题；导入不信任该表 |

不导出内部 UUID。连接 C 编号与原接入容量 C 编号在各表独立解析，导入为新项目时全部重新生成 ID。设备/接口/连接上限分别为 500/5000/2500；名称 1–100、型号≤200、备注≤1000、编号≤100，接口名同设备 trim 后唯一。

设备类型为交换机/路由器/防火墙/AP/终端/服务器/其他；角色为业务接入/上联/其他，状态为可用/预留/停用。连接要求不同设备的可用接口，每个接口最多一条连接。全部新输入字段均为普通文本，数字单元格（包括编号）、公式、超链接、富文本、日期及结构化值拒绝。表头冻结并提供列宽及中文枚举下拉。

未知或重复版本标记、启用后缺少任一新输入表、无标记却有新数据、孤立新表数据均拒绝；新输入有数据时必须有场地位置/业务需求/接入容量三张原输入表。读取或校验失败不落盘。派生问题逐项输出，单格不无限聚合文本。业务容量包括已连接可用接入口，手填值单独显示，不覆盖、不相加；未知需求保留待补充。

## B2 可选 PoE 与带宽表（B2 扩展至21表，含 C 为25表，当前含 D 共27表）

`填写说明` 增加独立“容量校核版本”，启用为1、缺省空；不改变其他版本。显式空计划仍启用，缺省不会自动启用。兼容旧5/8/12/16表；静态五表模板不变。四张输入和一张派生表如下（星号必填）：

| 工作表      | 顺序列                                                                                                                             |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| PoE电源预算 | 电源编号*、设备编号*、整机预算W、整机预留百分比*、备注                                                                             |
| PoE负载     | 负载编号*、连接编号*、供电接口编号*、受电接口编号*、单口供电预算W、设备端功耗W、损耗预留百分比、备注                               |
| 上联参数    | 上联编号*、连接编号*、起点接口编号*、终点接口编号*、起点速率Mbps、终点速率Mbps、带宽预留百分比*、备注                              |
| 上联业务    | 业务编号*、上联编号*、业务名称*、方向*、当前数量、单设备Mbps、并发百分比、增长百分比*、备注                                        |
| PoE带宽校核 | 校核类型、记录编号、关联编号、方向、名称、单位、已知需求、可规划容量/单口预算、余量、未知项数、公式与输入依据、校核状态、说明/问题 |

S001/Q001/U001/T001为四表本地编号，引用 E/P/C 设备/接口/连接代码，业务引用U编号；允许合法自定义编号，每表唯一、≤100且无控制字符。导入转换为与整个工程/设备/容量图无冲突的临时ID，再通过新项目导入重建全部ID与引用，不保存工作簿编号作内部身份。PoE允许在同连接两端指定供电方向；上联起终点必须与连接保存方向一致。

数值列为电源预算3/4、负载5/6/7、上联5/6/7、业务5/6/7/8。普通数字或严格非负十进制文本允许，最多3位小数，拒绝科学计数文本、符号、非有限、越界、额外精度、百分比有效数值格式、公式/超链接/富文本/日期/布尔；整数和界限仍由领域验证。普通数字20表示20%，不会按0.2换算。引号内/转义/填充/括号字面百分号依既有格式规则处理；ExcelJS往返丢失转义时可能成为有效百分号而被拒绝，建议普通数值格式。可空数值空为null；预留/增长必填不可空；0保留。文本列仅普通文本或空，数字也拒绝。单格最多32767字符，备注≤1000、业务名称1～100。W/Mbps和数量/百分比精确范围见[容量指南](capacity-planning.md)。

方向下拉为正向/反向；表头冻结、数值格式0.###。派生表只读保护，导入完全忽略其内容和表头，按UI相同的纯报告重算；问题逐条输出，未知数值空白，不能用篡改结果证明通过。预算与端口功率用W，上联逐方向用Mbps，输入依据、公式、已知小计、未知数量和所有不足/缺项保留；两个方向不相加。

重复标记（包括空标记）、未知版本、缺标记却有数据、启用但缺任一新输入表，或缺原工程/设备三表均拒绝；错误预览不返回可保存项目，确认导入仍为新项目。原有输入表头不变。

## C 可选现场验收表（C 扩展至25表，当前含 D 共27表）

三张输入表“验收清单”“验收结果”“整改复验”与派生“现场验收报告”，字段集中定义于 `src/domain/excel-schema.js`，解析位于 `electron/site-acceptance-excel.cjs`。独立“现场验收版本”标记仅允许 1/空，重复、未知、无标记有数据、启用却缺表均拒绝。旧5/8/12/16/21与静态五表模板保留。

K/R/X 编号表内唯一且只作本地引用；设备/接口/连接的 E/P/C 通过真实解析映射恢复，不能猜编号。要求历史快照、全部结果及失败/复验关联保留；来源 sourceId 不参与业务 ID 重建。派生表忽略并由领域报告重算。

文本与 JSON 列只接受真实普通文本；数字只接受有限普通数值或严格十进制整数文本。公式、超链接、富文本、Date、boolean、有效百分比格式与越界拒绝；文本≤32767字符、错误预览最多50条、输入文件≤10MiB。每项目≤500项/2000结果/1000整改，证据≤8192 UTF-8字节、8指标，未知 null 与 0 不混同。最大合法数据真实序列化测试不代表所有不可压缩极限文本都满足10MiB输入守卫。详见[现场验收](site-acceptance.md)。

## D 可选端口逻辑配置（当前动态输出共27表）

在原25表之后追加下列表，不改变旧表头与固定列序。独立“逻辑配置版本”标记允许数字1/空；重复标记、未知版本、无标记有数据、启用却缺输入表或原工程/设备输入表均拒绝。显式空计划可往返；旧5/8/12/16/21/25表缺省不启用逻辑配置，静态五表模板不变。

| 工作表       | 顺序列                                                           | 上限 |
| ------------ | ---------------------------------------------------------------- | ---- |
| 端口逻辑配置 | 接口编号*、逻辑模式*、业务网段编号JSON、Access VLAN、允许 VLAN   | 5000 |
| VLAN配置校核 | 接口编号、网段编号、连接编号、业务VLAN、状态、校核代码、具体问题 | 派生 |

接口引用真实P编号，网段为JSON字符串列表，例如 `["N001"]`，支持合法自定义工作簿编号，不按逗号拆网段编号。每接口最多一行；Access最多关联一个网段，Trunk最多128个，所有引用必须属于本项目。逻辑模式为Access/Trunk；物理接口角色保持原表契约。

输入表全部字段仅接受普通文本，包含VLAN也必须是文本；拒绝数字单元格、公式、超链接、富文本、日期等。VLAN为1～4094严格整数文本；允许列表以逗号分隔，元素去除两侧空白，不得重复。空表示未知，“无”表示明确空列表；Access VLAN空同样未知。所有引用在导入为新项目时重新生成内部ID。输入解析或校验失败不保存项目。

“VLAN配置校核”为保护的派生表，导入完全忽略其内容和表头，使用与界面相同的纯领域函数重算。每条问题保留P/N/C编号、严重程度、代码和说明；结果只校核登记连接段显式声明的业务，不证明现场路径、路由、隔离、STP或LAG有效。使用语义与现场验收交接见[拓扑与 VLAN 指南](engineering-topology.md)。
