# IP 表格与紧凑网格

IP 显示现在支持「表格 / 紧凑网格」，使用相同的设备图标、地址末段数字、图例和选中样式，适配浅色、深色与大字模式。

## 适用入口

- **IP 地址探测**：结果区域可以随时切换，切换不重启、不重复执行探测。开始前展示目标地址，标为未探测；开始后固定显示本次任务目标。
- **项目工作台 → IP 地址台账**：表格继续展示登记记录；紧凑网格展示选中网段的完整地址空间，包括未登记地址、网关、DHCP 池、网络地址和广播地址。
- **IPv4 地址规划 → 已保存网段**：点击网段名称后，地址台账区域也使用同一套切换和紧凑视图。
- **诊断记录 → 查看 IP 探测记录**：支持表格与紧凑网格；历史记录保留原探测时间及未完成状态。

## 默认方式

进入左下角「设置 → 显示设置 → IP 默认显示方式」，选择表格或紧凑网格并保存。

默认方式保存在本机工作区的 `settings.ipView`，桌面版使用 SQLite，浏览器预览使用 localStorage。首次使用和旧版数据缺少该设置时保持原来的表格方式。设置支持预览、放弃修改与保存，保存后下次启动仍生效。

页面上的切换是本次会话共用的显示方式，各入口保持一致；临时切换不会改写已保存的默认偏好。设置中修改默认方式后立即应用。

## 台账与探测分开表达

网段视图的图标颜色表示地址用途：

| 用途           | 含义                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 可分配（台账） | 未在本项目相同 VLAN 的台账、网关或 DHCP 池中占用，也没有最近有响应的未登记提示 |
| 在用登记       | 人工登记为在用；未收到探测响应也不会变成空闲                                   |
| 规划预留       | 为未来设备保留的地址                                                           |
| 检修           | 人工登记为检修                                                                 |
| 网关 / 上联    | 网段规划中的网关地址；有台账记录时，详情另列登记状态                           |
| DHCP 池        | 动态分配范围，不支持直接登记为静态地址                                         |
| 有响应·未登记  | 最近有探测响应但尚未登记，需要核实用途                                         |
| 网络 / 广播    | 普通子网的保留地址，不允许登记；`/31`、`/32` 按自身规则处理                    |

右下角圆点是独立的最近探测信息：绿色有响应、灰色无响应、红色错误；无圆点表示没有记录。点击地址可查看完整 IP、设备资料、登记状态、探测时间及依据。

探测信息取当前项目的扫描和 Ping 历史，以及当前扫描已返回的结果；按每个 IP 的记录时间选择最近一次，忽略路由中间节点。它来自本机当前网络视角，不能确认同址的不同 VLAN 上分别是哪台设备，也不是持续在线监测。无响应不等于现场空闲，地址登记仍需核实现场配置。

点击可分配地址后可以「登记此地址」，自动填入该 IP；已登记地址可以编辑或移除。网关单独登记时默认设备类型为路由器 / 网关、状态为预留。来自重叠网段的已有登记会回到其所属网段编辑，避免重复登记。

## 地址范围与筛选

- 每次展示一个地址区块，最多 256 个 IP；显示完整地址范围，格内数字为地址的最后一段。
- 探测视图遵循实际扫描范围，普通 CIDR 不探测网络及广播地址；台账网格则显示这些地址并明确标记不可分配。
- 大网段按数学区间计算当前块，支持上一块、下一块及输入页码；不会生成整个 `/8` 或 `/0` 的地址列表。
- 台账支持按地址用途、最近探测和原有登记状态筛选。图例数量是当前区块的用途总数，显示数量反映当前筛选结果。
- 搜索完整 IP 会跳转到当前所选网段对应区块并精确定位。部分 IP、设备、位置或负责人搜索仅筛选当前区块；跨网段查找登记设备可使用表格搜索。
- 探测中的未返回地址标为「待返回」，停止后的未返回地址标为「未完成」，不会当成无响应。

## 实现位置

- `IpViewToggle.vue`：各入口共用切换控件。
- `IpAddressGrid.vue`：设备图标、末段地址、状态标记、本机标记和最近探测圆点。
- `ScanGrid.vue` / `AddressMap.vue`：探测视图与台账视图。
- `src/domain/scan-view.js` / `src/domain/address-map.js`：目标地址、分块、用途分类及最近探测合并。
- `src/ip-display.js` 与 `App.vue`：共享显示状态和当前项目的诊断上下文。

验证使用隔离数据目录。真实诊断只对回环地址执行；台账截图的探测状态来自固定测试记录，没有扫描图中的局域网地址。覆盖新旧设置、SQLite 重启恢复、预览与取消、完整 IP 定位、`/0` 分块、`/31` 和 `/32`、跨 VLAN 与项目隔离、登记操作以及深色大字模式。
