# PoE 与上联容量规划

在项目工作台选择“PoE与带宽”。先在场地页建立区域，再于“设备与连接”登记设备、接口和连接；本页可直接前往设备清单。容量计划可选，旧项目不自动增加数据。

## 输入与操作

分别添加/编辑/删除整机预算、PoE负载、上联和业务项。预算选择设备；PoE选择连接与供电接口，自动显示另一端为受电接口；上联选择连接，显示并保存已登记起点/终点快照。业务关联本项目上联，正向/反向显示真实设备、区域、接口；方向互不相加。

所有空数字表示待补充，0表示明确零。新建默认整机/带宽预留20%、损耗预留20%、并发100%、增长20%，可编辑，属于工程估算而非现场实测。备注≤1000、业务名称1～100字符。预算/负载/上联/业务各上限500/2500/500/500。设备预算按设备唯一，负载和上联分别按连接唯一，同一连接可同时用于PoE与带宽。

| 输入                      | 范围                        |
| ------------------------- | --------------------------- |
| 整机预算 W、两端速率 Mbps | 空或0～1000000，最多3位小数 |
| 单口预算/设备端功耗 W     | 空或0～1000，最多3位小数    |
| 单设备 Mbps               | 空或0～10000，最多3位小数   |
| 当前数量                  | 空或0～100000整数           |
| 损耗/并发百分比           | 空或0～100整数              |
| 整机/带宽预留百分比       | 必填0～100整数              |
| 增长百分比                | 必填0～1000整数             |

保存失败时对话框保留原草稿，可修正或重试；保存期间禁止重复提交，焦点保留在模态中。切项目关闭旧草稿。删除被业务引用的上联，或被校核引用的设备/接口/连接，以及更改连接端点导致快照失配，均拒绝，不静默级联；先处理相关引用。

## PoE估算（单位W）

设备端功耗乘 `(100 + 损耗预留%) / 100`，向上取整到0.001W，是供电端需求。单口余量为单口供电预算减供电端需求。整机预算乘 `(100 − 整机预留%) / 100`，向下取整到0.001W；按供电接口当前所属设备汇总逐负载已知需求，与整机可规划预算比较。

例如两条12W负载、25%损耗，各15W、共30W。40W整机预留20%可规划32W，余量2W；若单口预算14W，则单口不足，设备整体仍不足。未知需求保留已知小计/未知负载数，余量待补充；缺单口预算不会隐藏已知需求。预算未登记或只有预算而无负载均待补充；已确定不足优先显示，同时保留缺项。

损耗是手填估算，不按线长推导。冗余电源须手工分配每条连接的真实功耗；不会自动减半或复制总功耗。不认证IEEE PoE兼容、线缆、环境或现场供电。

## 上联估算（单位Mbps）

每条链路两端速率较小值乘 `(100 − 预留%) / 100`，向下取整到0.001Mbps，得到每方向可规划带宽。业务规划数量为 `当前数量 + ceil(当前数量 × 增长% / 100)`。每条业务以规划数量乘单设备Mbps及并发百分比，向上取整到0.001Mbps，再按关联上联和方向求和。每方向余量为该方向容量减需求，两个方向独立。

例如1000↔100Mbps、20%预留得到80Mbps。40个终端、20%增长、2Mbps/端、50%并发，规划48个、正向48Mbps、余量32Mbps；反向60Mbps仍余20Mbps，不能与正向相加。任一业务输入未知，该业务及本方向余量待补充；已知小计不足仍保留。只知道一端速率不能判满足，但已超过其可规划上界时可判不足。没有业务项待补充；某方向没有业务明确显示0和“无业务项”。

报告与Excel共用纯领域报告及精确取整；不叠加多链路、主备、LAG，不自动路由，也不叠加场地需求。所有结论是“按已登记参数估算”，不替代现场验收。
