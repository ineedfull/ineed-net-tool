# NetTool 功能参考

[返回产品首页](../README.md) · [开发指南](development.md)

本页保留现有功能的详细行为与容量边界。工程拓扑、PoE、验收等新模块以链接的专项指南为准。

## 功能

- 操作提示：成功提示支持右侧 × 手动关闭，6 秒后自动收起；鼠标悬停、键盘聚焦、切离页面或窗口隐藏时暂停，恢复后重新计时。失败提示支持手动关闭，不自动消失；字段校验、诊断结果和必要的规划警告保持展示。

- IP 双视图：探测、项目台账、网段地址及扫描历史可切换表格 / 紧凑网格；设置中保存默认方式。网格区分登记用途、网关、DHCP 池、可分配地址，并叠加最近探测信息。见 [IP 显示说明](ip-views-2026-09-21/README.md)。

- 项目工作台：应用默认首页，统一管理客户、现场位置、负责人、规划 / 使用 / 归档状态；包含地址规划、场地与需求、设备与连接、工程拓扑、PoE与带宽、IP 地址台账、接入与互通（适用项目）、维护记录页签。地址规划不再占用独立侧栏入口；同一项目切换页签或工具时保留规划草稿，切换项目重置编辑表单，避免误存到其他项目。
- 企业办公室 / 园区需求规划：在项目“场地与需求”中组织楼栋、楼层和区域，分别记录有线、无线客户端、AP 等业务数量与增长预留；关联已有网段，校核区域业务接入端口与网段总地址 / 静态 / DHCP 容量。显示公式、已知小计和待补充事项，随项目保存并支持工程 Excel 交接；需求变化不自动改写已有 IP。使用说明见[工程规划](network-engineering.md)。设备与连接页签登记设备、接口、连接和占用，按已登记可用业务接口校核容量；手填容量独立保留。“现场验收”登记人工检查、诊断引用快照、整改与显式复验闭环，支持当前 27 表 Excel 交付，见[现场验收指南](site-acceptance.md)。“PoE与带宽”登记整机预算、逐连接PoE负载、上联端点速率与方向业务，按已登记参数估算，未知保留待补充；详见[PoE与带宽指南](capacity-planning.md)。
- 工程拓扑：从现有设备、接口、连接生成位置筛选图，直接打开原记录编辑。接口可独立登记 Access / Trunk、关联业务网段及 VLAN；检查已声明连接段的承载参数，问题可显式交给人工现场验收，未知保持待补充。详见[拓扑与 VLAN 指南](engineering-topology.md)。
- 场景模板：小型办公室、办公分区网络、视频监控、大型项目三运营商双网。大型模板独立规划内外网，提供电信 / 联通 / 移动线路台账及可编辑、排序的跨网访问规则，默认隔离；支持 SQLite 与 Excel 往返保存。互通策略需在现场防火墙配置生效，见 [大型项目说明](enterprise-2026-09-21/README.md)。创建前预览私有地址空间、VLAN、网关和 DHCP 池；只预留网关，实际设备按现场登记。
- IP 台账：设备类型、预留 / 在用 / 检修、位置、负责人、MAC、备注；搜索筛选、编辑移除、空闲地址建议、一次最多 128 条批量登记。同项目同 VLAN 不得重复 IP，静态地址避开 DHCP 池。
- SQLite：项目、网段、地址、维护及诊断记录分表持久化，事务保存；自动迁移旧 JSON 并保留原文件。
- Excel：下载中文模板、导出当前项目、校验预览后导入为新项目。详细操作与表格格式见 [项目与 Excel 指南](network-projects.md)。

- 网段计算：独立菜单，不依赖项目选择；提供 CIDR / 点分掩码计算、/0 /31 /32、地址容量与范围、首个可用地址的网关建议、组播标准范围 `224.0.0.0/4` 及作用域说明，以及按设备数量 VLSM 划分。单独填写的掩码优先于 CIDR 前缀。切页保留输入与划分结果，改变输入后清除过时的划分结果。本机网卡入口可直接带入计算。
- 计算结果可“加入项目规划”：选择目标项目、编辑网段名称，单个或整批追加保存；地址重叠时提示，不覆盖已有网段、地址分配或未保存的规划草稿，不自动切换当前项目。网关建议不是探测结果，保存时不自动采用；组播范围与计算的子网无关。“探测此网段”仅带入目标，不自动启动扫描。
- 按设备数量划分：逐行增删用途、设备数量与额外预留，最多 128 个子网，默认每个子网另为网关预留 1 个地址（可关闭）。结果展示掩码、可用范围、广播地址、网关建议、容量与余量；支持单独编辑用途 / 数量 / CIDR / 实际网关和移除子网，广播地址随 CIDR 自动重算。编辑时校验地址对齐、父网段范围、同批子网重叠、容量和网关合法性。采用全部建议只填未设置的网关，保留自定义值；手动设置网关也会计入容量。需求变更后需重新生成才能保存，再生成会替换手动调整。选择的实际网关随网段保存，设备与预留数量记入备注；旧项目不自动修改。
- 项目工作台 → 地址规划：管理当前项目的网段名称与用途、网关、VLAN、DHCP 范围和设备地址分配，支持 JSON 规划导入导出。网关可选填、校验后随规划保存；旧规划仍归入默认项目。子网批量划分已移动到独立计算菜单，已有 SQLite 数据不需要迁移。
- IP 探测：单 IP、CIDR、起止范围；ICMP、TCP、ICMP + TCP；默认 32 路地址并发，可调 1～128。同一地址的协议与 TCP 端口并行探测，首个有效响应取消其余检查；所有地址合计最多 128 个活动原生探测，避免进程/套接字无限增长。单次最多 65,536 个地址（支持完整 /16），按最多 256 个地址一批依次调度，显示总进度、当前批次、耗时和吞吐，支持暂停/继续/停止。启动前预览规模并校验范围。

扫描结果完整保留，不再只保留最后 4096 条。实时与历史表格每页 100 条，网格只生成所选地址区块的最多 256 个单元；状态筛选作用于全部已完成结果，导出不受分页或筛选影响。停止任务保存已完成部分，未返回的地址不会标记为无响应。单次任务仍有 65,536 个地址的保护上限；超出时提示实际数量和上限。

扫描保留用户设置的响应超时；仅把原生 Ping 额外等待余量从 700ms 缩至 50ms，独立 Ping 工具行为不变。结果按 50ms 或每 64 条批量推送到界面，结束前完整刷新。暂停使用等待通知，不逐路循环轮询。性能取决于响应率、超时、并发和本机资源，局域网可先用默认 32 路，网络较弱时调低。

- Ping：IPv4 / 域名、请求间隔、超时、次数或持续运行，以及 0～65,500 字节自定义数据载荷（默认 56 字节，不含协议头；大包可能分片，不禁止分片）。时延曲线、丢包与耗时统计。切页不中断；系统输出、执行参数、时间、退出码和错误随诊断记录保存，支持查看、复制及导出 TXT。明细与原始输出保留最近 500 次请求，统计覆盖全部请求；历史任务保留最近 100 次。旧记录可查看原有输出，未保存的参数不会补造。详见 [Ping 使用说明](ping-tool-2026-09-21/README.md)。
- 路由：原生 traceroute、逐跳 IP / 耗时 / 超时、是否到达目标、相同目标上次路径对比、原始输出。
- DNS 查询：A、AAAA、CNAME、MX、TXT、NS、SOA、SRV、CAA、PTR，可使用系统 DNS 或指定服务器 `IP:端口`，展示记录、查询耗时和可获取的 TTL；PTR 输入 IP 地址。
- 端口扫描：单个域名 / IPv4 的 TCP 端口或范围，支持 1～65,535，默认 64 路、最多 128 路并发，每批最多 256 个。区分开放、拒绝连接、超时及错误；状态筛选和每页 100 条展示不影响完整结果保存与导出。不发送应用层探测数据，超时不能直接判断端口关闭。
- 网速与质量：下载测速使用自行填写的 HTTP / HTTPS 文件地址，默认 15 秒或 64 MiB，先达到限制即停止；可设 1～60 秒、1～256 MiB，流式读取而不保存文件。显示实际吞吐率、下载量与停止原因；流量最多可能多接收一个数据块。仅测该下载链路，不代表宽带套餐速率，暂不含上传测速。链路质量可选 ICMP / TCP，采样 2～300 次，展示失败率、最小 / 平均 / 最大时延、P95 与相邻成功样本的平均时延差（抖动）；失败样本会中断相邻关系。TCP 连接失败不等于目标离线。
- 证书检查：支持端口、SNI / 校验名称和到期提醒阈值，展示有效期、剩余天数、域名匹配、证书链信任、颁发者、SAN、指纹及 TLS 协议。诊断握手允许读取无效证书，但会明确显示校验失败，且不发送应用数据；下载测速仍严格校验证书。信任结果基于应用运行时 CA，暂不检查吊销状态；证书链显示服务器提供的部分。
- 诊断记录：自动保存最近 100 个任务；Ping 明细最近 500 条，统计覆盖全部请求。浅色/深色/系统主题，大字模式。

“查看记录”使用独立的大尺寸详情窗口，点击后立即显示；详情内部滚动，关闭和导出按钮保持可见。支持 Esc、关闭按钮或点击遮罩返回列表，保留原列表滚动位置及按钮焦点。扫描分页 / 网格、各工具结果、Ping 目标信息与原始日志统一在窗口内查看，不修改已有历史数据。

新增工具支持停止、切页继续运行、按项目保存诊断记录、重启回看及 JSON 导出；下载中断时保留已接收量和部分测速结果。沿用现有 SQLite 表结构与历史保留规则，升级不重建数据库、不清除现场配置。

Ping 的“目标信息”自动显示主机名、MAC 和厂商／地址注册机构。解析目标 IP 后与 Ping 并行查询，每次任务只获取一次，总查询时限 2.5 秒；查询失败不改变 Ping 的收发状态，结束时保存查询快照，历史回看及 JSON 导出包含这些字段。主机名来自本机系统或反向 DNS（PTR），没有记录时显示未获取；尚未包含 NetBIOS/mDNS 主动发现。MAC 来自本机网卡或直连路由的精确邻居记录，跨网关不借用网关 MAC；回环没有物理 MAC，邻居缓存／代理 ARP 可能影响结果。厂商用附带的 IEEE MA-L/MA-M/MA-S 库离线匹配，本地管理／随机 MAC 不推测厂商。旧历史不补造这些信息。

目标信息的 macOS 路径已通过桌面验证；Linux `ip`、Windows PowerShell 的查询分支尚未进行真机验证。IEEE 数据来源与更新方式见 [离线地址库](../electron/data/README.md)。

“无响应”不等于地址空闲。“连接拒绝”表示 TCP 收到了响应，但端口并未开放。已分配地址是用户规划数据，不会根据扫描结果自动改写。
