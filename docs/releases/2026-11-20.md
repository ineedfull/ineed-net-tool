# NetTool 0.1.1 测试版

发布日期：2026-11-20。

## 本版调整

- 完善录入表单和项目交互的一致性，整理弹窗、Excel 及工程模块的职责。
- Excel 与诊断导出采用安全写入流程，保留项目交付与诊断记录的各自边界。
- 补充办公室规划、IP 台账、本机 Ping 与 Excel 交换[快速上手](../quick-start.md)，修正当前 27 表说明。

## 安装与验证范围

从[官网下载页](https://nettool.ineedfull.com/downloads/)选择系统与 CPU 架构，按页面列出的文件和构建标识下载。当前只有 Electron 版，自带 Chromium，内存和磁盘占用相对较大。构建命令与矩阵见[打包指南](../desktop-packaging.md)。

本版按测试安装包分发，未配置 macOS Developer ID / 公证或 Windows Authenticode 正式签名。Windows 包使用 Linux/Wine 交叉构建；生成文件不代表 Windows/Linux/macOS Intel 已全部通过实机安装升级验收。本批实际构建、摘要与运行检查以发布交接记录为准。

安装前退出应用，保留原应用身份和数据目录；完整备份先退出后复制用户数据目录。项目 Excel 不包含诊断历史，见[项目与 Excel](../network-projects.md)。本批不发布自动更新 feed。
