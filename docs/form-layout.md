# 录入表单排版

NetTool 复用 `src/style.css` 的控件样式与 `src/styles/projects.css` 的 `.field-grid`。单行文本、数字、原生日期 / 日期时间和下拉框使用 `--control-height: 32px` 的外框高度；字号沿用普通 12px / 大字 13px。多行文本独立按 rows 和内容设置高度；复选框、场景单选与设置开关保留各自紧凑样式。

完整表单使用 `.field-grid`：两列等宽，列宽允许收缩，行列间距 16px，标签与控件间距沿用 7px。同一行标签按底部对齐，长标签换行时控件仍对齐。`.full` 跨两列。标签内的单行控件和多行文本填满可用列宽；尤其覆盖全局数字输入框 140px 的工具栏默认值。诊断工具栏与子网编辑中的紧凑数字框仍为 140px，不因工程表单扩展而膨胀。

辅助说明、警告应放在独立的 `.full` 行；不要通过大 margin、固定标签高度或空标签制造间距。文本域不参与单行等高规则。继续保留 label / aria-label、必填限制、输入类型和原生选择行为。宽度低于 520px 时表单按既有媒体查询变为单列；弹窗仍使用原生模态焦点、内部滚动和固定可见页脚。

验证命令：先 `npm run build`，再 `npx playwright test tests/ui/form-layout.spec.js`。测试运行实际 macOS Electron，使用临时隔离数据，不发起扫描；覆盖浅 / 深色、普通 / 大字、展开 / 折叠导航及 1440×900 / 920×620 共 16 种组合。实测页面包括项目创建和编辑、场地需求及接入容量、设备接口连接、四类 PoE / 上联参数、台账、运营商线路和互通规则、维护日期、验收三类表单和复验闭环、地址规划、子网计算 / 划分 / 编辑 / 加入项目、全部诊断参数及设置。

截图和逐控件几何数据默认在 Playwright `testInfo.outputPath('evidence')`，也可用 `NET_TOOL_FORM_EVIDENCE_DIR` 指定持久目录。回归检查数字列填满、单行高度、同排控件位置、弹窗和页面横向溢出、页脚可见、模态焦点。界面检查不替代现场网络验证、原生日期选择器弹出层操作或其它操作系统 / 安装包验收。

## 浏览器隔离复测

`npx playwright test -c playwright.form-layout.config.js` 运行同一套表单检查，使用独立浏览器 localStorage 数据及 5197 回环预览服务，不启动 Electron 窗口或网络诊断。若使用本机 Chrome，可加 `NET_TOOL_FORM_CHANNEL=chrome`；默认使用 Playwright Chromium。原 `npm run test:ui` 保持真实 Electron 验证路径。

同排字段按网格项的水平分列及垂直重叠范围识别，不依赖标签顶部相等，避免长标签换行后漏测。2026-10-31 浏览器复测覆盖 34 类表单 × 16 种显示组合及首个数字框基线，共 545 个记录、484 对同排控件，顶部差均为 0px。本轮未发现新的实际排版缺陷，未改生产样式；浏览器结果不替代原生桌面或安装包验收。
